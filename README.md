# Битрикс24 для GrigDesk

Драйвер трекера задач [GrigDesk](https://github.com/EvilDevRu) для порталов
Битрикс24. Подключается за минуту — токеном или обычным логином и паролем; адрес портала
  достаточно указать именем, `https://` подставится сам —
и выводит задачи портала на доску GrigDesk рядом с собственными задачами.

## Что даёт

- Задачи портала на доске: списки, карточки, статусы, проекты и исполнители.
- Вход логином и паролем работает и на бесплатных облачных порталах Битрикс24:
  драйвер сам продлевает сессию и проверочный код портала.
- Создание задач из GrigDesk, завершение и возобновление.
- Чтение и добавление комментариев к задачам.
- Правка названия, описания, исполнителя и срока задачи.
- Поиск пользователей и групп портала.
- Один внешний трекер на доску; собственные задачи GrigDesk никуда не деваются.

Пока не поддерживается: учёт времени (таймер), вложения и виджеты портала.

## Установка

Нужен GrigDesk с поддержкой внешних драйверов (контракт 1).

**Из каталога** — в GrigDesk откройте «Настройки трекера» → «Установить из Git»
и выберите карточку «Битрикс24».

**По ссылке** — в том же диалоге вставьте адрес этого репозитория:

```
https://github.com/EvilDevRu/grigdesk-b24
```

## Настройка

В «Настройках трекера» укажите адрес портала (например,
`https://myportal.bitrix24.ru`) и выберите способ подключения.

### Токен доступа — для порталов с подпиской

1. В портале откройте «Разработчикам» → «Другое» → «Входящий вебхук»
   (раздел доступен на платных тарифах).
2. Выдайте вебхуку права на задачи, пользователей и группы, сохраните.
3. Из адреса вебхука вида `https://myportal.bitrix24.ru/rest/7/СЕКРЕТ/`
   скопируйте последний сегмент — это и есть токен.

### Логин и пароль — для бесплатных порталов

Введите логин и пароль пользователя портала — драйвер входит обычной формой
и работает через сессию. Если портал требует код из СМС, приложение-генератор
или капчу при входе — войдите в портал браузером один раз и повторите
подключение.

Сменить способ можно в любой момент в тех же настройках.

## Вопросы и проблемы

Если подключение не проходит — нажмите «Проверить соединение»: драйвер
сообщает конкретную причину (неверный токен, код/капча, нехватка прав).
Ошибки и предложения — в [issues репозитория](../../issues).
