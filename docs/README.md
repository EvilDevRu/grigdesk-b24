# Стоковый Битрикс24

Внешний драйвер контракта 1: исходящий HTTPS REST с access token в теле POST.
В настройках доски задаются origin портала `baseUrl` и секрет `accessToken`.
Пакет поддерживает чтение, создание и завершение задач, пользователей и проекты.
Таймер, комментарии, вложения, правка и виджеты отключены через capabilities.

Ядро не импортируется: `types/` содержит локальный снимок общего контракта.
Host предоставляет реквизиты и необязательный fetch; обычный запуск использует системный fetch.
Сетевые ошибки скрывают токен, мутации не повторяются, redirects запрещены, срок — 30 секунд.
Текст статуса выдаётся самим пакетом в dashboard и taskDetail.

Проверки запускаются из checkout GrigDesk через `tests/run-node-tests-safe.sh`,
с `--test-concurrency=2` и `NODE_TEST_MAX_RSS_MB=4096`, передав `tests/*.test.js` этого пакета.
